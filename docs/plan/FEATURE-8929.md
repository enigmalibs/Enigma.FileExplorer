# FEATURE-8929 — New application icon

**Status:** DONE
**Type:** FEATURE
**Branch:** `feature/feature-8929-new-app-icon`
**Run:** feature/2026-10-29-uniform-enigma-apps

## Objective

Replace the application icon with the new set in `C:\Dev\EnigmaLibs\Branding\Apps\final\file-explorer`
everywhere the repository carries it.

## Context & constraints

- **The new set** is generated by the sibling Branding repository (`Branding/Apps/export.py`, variant FE-E2,
  "Open folder in the Soft palette"):
  - `enigma-file-explorer.svg`, the master;
  - `enigma-file-explorer.ico`, ten 32-bit PNG frames: 16, 20, 24, 32, 40, 48, 64, 96, 128, 256;
  - `png/enigma-file-explorer-N.png` for the same ten sizes, each byte for byte the `.ico`'s frame.
- **There is no `-small.svg`.** Per `export.py`, "an application without one uses its master for every
  frame". The repository's `packaging/icon/enigma-file-explorer-small.svg` belongs to the old artwork.
- **Where the icon lives today:**
  - `src/Enigma.FileExplorer.Desktop/Assets/app.ico` (six frames) — the `ApplicationIcon` and
    `MainWindow.Icon`;
  - `Assets/app-256.png` — the About dialog's image, the `.ico`'s 256 frame byte for byte;
  - `packaging/icon/enigma-file-explorer.svg` and `-small.svg` — the old masters, with an in-repo
    `rsvg-convert` recipe in the header comment.
- `AppIconTests.TheIcon_HoldsSixSquare32BitPngFramesFrom16To256` pins six sizes.
- The Linux hicolor copies come with FEATURE-6FDB, which takes them from this same set.

## Steps

1. Copy byte for byte:
   - `enigma-file-explorer.ico` → `src/Enigma.FileExplorer.Desktop/Assets/app.ico`;
   - `png/enigma-file-explorer-256.png` → `src/Enigma.FileExplorer.Desktop/Assets/app-256.png`;
   - `enigma-file-explorer.svg` → `packaging/icon/enigma-file-explorer.svg`.
2. Delete `packaging/icon/enigma-file-explorer-small.svg`.
3. `AppIconTests`:
   - the frame test expects the ten sizes (renamed accordingly);
   - the class comment says the frames come from the Branding export, not from a hand packing.
4. Grep for stale mentions of the small SVG or of six frames (`docs/` excluded) and fix them.

## Acceptance criteria

- The three destinations hold the new files byte for byte; the small SVG is gone.
- `AppIconTests` pins ten frames and the 256 copy.
- The build has zero warnings; the whole suite is green.

## Out of scope

- The Linux icon copies (FEATURE-6FDB).
- The application's own accent colours.
- The version and the release notes (FEATURE-26E7).
